推理互動工作區 的  特徵值剩餘位置區 (基於解答區推導) 對使用者沒有幫助，我想改成 推理過程紀錄區

推理過程紀錄 主要用來記錄自動推理所使用的推理依據，以及使用者自己選擇的選項，使用者可以自行編輯推理依據

- 在 state 裡增加一個紀錄推理過程陣列的屬性
- 此陣列將會紀錄如下物件 `{ id:自動編號, feature: "國籍", value: "英國人", position: 3, desc:"英國人 位於 第 3 個位置", rules: [ { id: rule-id, desc: rule-desc },... ] }`
  - 推理結果 `feature: "國籍", value: "英國人", position: 3, desc:"英國人 位於 第 3 個位置"`
  - 推理依據 `rules: [ { id: rule-id, desc: rule-desc },... ]` 取 規則 rule一部分
- 紀錄方式如下:
  - 當自動推理進行時，一個特徵值有唯一最終可行位置，有兩種可能：「其中一條規則給出了唯一可行位置」、「沒有一條規則給出了唯一可行位置，但有多條規則分別給出限制，最終唯一確定可行位置」。
  - 如果是「其中一條規則給出了唯一可行位置」，那很顯然這就是推理依據，針對此特徵值不用紀錄其他規則
  - 如果是「沒有一條規則給出了唯一可行位置，但有多條規則分別給出限制，最終唯一確定可行位置」，針對此特徵值，需要記錄這些對限制可行位置有幫助的規則，不用紀錄對限制可行位置沒有幫助的規則
    - 不是記錄所有提到這個特徵值得規則
    - 順序會影響紀錄的規則，不過沒關係，只要是有效的推理依據即可
  - 範例如下：

    ```
    特徵值 英國人 剩餘位置 [2,3,4,5]
    規則#3 xxxxxxx 英國人 可行位置 [3,4,5]
    規則#5  oooooooo 英國人 可行位置 [2,3,5]
    規則#8 xxxxxxx 英國人 可行位置 [3,5]
    規則#10  ooooooooo 英國人 可行位置 [2,4,5]

    先看 規則#3 可行位置 [2,3,4,5] => [3,4,5] 數量減少 有用 => 紀錄
    再看 規則#5 可行位置 [3,4,5] => [3,5] 數量減少 有用 => 紀錄
    再看 規則#8 可行位置 [3,5] => [3,5] 數量不變 沒用 => 不紀錄
    再看 規則#10 可行位置 [3,5] => [5] 數量減少 沒用 => 紀錄
    => 推理依據 `rules: [ { id: 3, desc:xxxxxxx }, { id: 5, desc:oooooooo }, { id: 10, desc:ooooooooo } ]`

    如果換一個順序，可能推理依據是 #8 #10，都對，不過只記一種就好，不用全部
    ```
  - 對於使用者自行選擇的特徵值，則記錄  `{ feature: "國籍", value: "英國人", position: 3, desc:"英國人 位於 第 3 個位置", rules: [  ] }` 規則部分為空
- 推理過程紀錄區以表格顯現，欄位分別是推理結果編號、推理結果簡要描述、推理依據規則描述。
  - 推理結果編號為自動編號，無法編輯
  - 推理結果簡要描述 如 "英國人 位於 第 3 個位置"，無法編輯，而是根據使用者在解答區的選擇或者自動推理的結果得出
  - 推理依據規則描述 是一個小表格，一個規則佔一橫列，就是羅列 rule-desc。每一個都是選擇元素，可選項為規則描述語句(僅和此特徵值有關的)
- 解答區和推理過程紀錄區高度關聯
  - 當用戶在解答區選擇某一個特徵值，會觸發相應的推理結果紀錄以及紀錄區的渲染。不論用戶將特徵值換一個或者重置某一個特徵值，都要在陣列修改以及刷新紀錄區。(所以 userGrid 需要記錄對應的推理結果編號，方便刷新)
  - 推理過程紀錄區也可以編輯，每一條推理結果允許刪除，而對應的在解答區的特徵值會重置，並觸發相應的計算和渲染
  - 推理依據規則描述 每一條規則是可選的，可以新增新的依據，也可以刪除依據

# ===================

我發現一個麻煩點，自動推理的推理依據可以簡單的限縮於與特徵值相關的規則之中，再加一條 通用規則G1。
但用戶自行推理的結果卻可能涉及到所有規則，所以不能給推理依據縮小規則範圍。

進行以下修改：
- 給每一筆推理結果新增一個 flag 用來記錄來自自動推理或者來自使用者自行推理
- 如果來自自動推理，用戶無法修改推理依據，且顯示的推理依據限縮於與特徵值相關的規則以及 通用規則G1
- 如果來自使用者自行推理，用戶可以修改推理依據，且推理依據來自所有規則和通用規則
